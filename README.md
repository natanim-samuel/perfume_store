# 🌸 Perfume Store

A Flutter application designed to provide a digital shopping experience for perfume products.

## 📌 About the Project

Perfume Store is a mobile application concept focused on perfume browsing and online shopping experiences.

The project explores mobile UI development, product presentation, and user interaction using Flutter.

## ✨ Features

- 🌸 Browse perfume products
- 🛍️ Product presentation
- 🔍 Explore product information
- 🎨 Modern user interface
- 📱 Mobile-friendly design
- 🛒 Shopping experience

## 🛠️ Technologies Used

- Flutter
- Dart
- Material Design

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/natanim-samuel/perfume_store.git
   ```

2. Navigate to the project:

   ```bash
   cd perfume_store
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
